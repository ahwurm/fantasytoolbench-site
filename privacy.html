Privacy

fantasytoolbench runs entirely in your browser. Rosters and draft sessions you enter are processed client-side and stored only in your own browser's local storage. They are never uploaded.

No accounts. No analytics. No tracking scripts. No cookies set by us.

Hosting is GitHub Pages, so GitHub's standard server logs apply (GitHub privacy statement).

If an optional email form appears on the site, it submits only what you type into it, via Formspree (Formspree privacy policy). Skipping it changes nothing about the tools.
